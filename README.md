# FoodDelivery v2.0 🍕

Веб-приложение (MVP) для быстрого онлайн-заказа еды, разработанное в рамках учебного Спринта №2.

## Архитектура файлов проекта:
- `app.py` — серверная логика на Python и интерфейс.
- `orders.json` / `bonus.json` — файловые базы данных.
- `USER_GUIDE.md` — руководство для клиентов.
- `RETROSPECTIVE.md` — анализ результатов спринта.

## Установка и запуск:
```bash
pip install flask
python app.py
```
